# Parallax MVP (a) — SDK build

Target: OpenWrt 25.12.x, x86/64, apk. The supported package build runs in GitHub Actions.

The workflow selects the SDK by parsing the official release directory listing, downloads
both the SDK and combined-efi image, and validates their official SHA-256 checksums.

The two source directories are copied into the extracted SDK package directory:

    cp -a parallax "$SDK_DIR/package/parallax"
    cp -a luci-app-parallax "$SDK_DIR/package/luci-app-parallax"

Then:

    ./scripts/feeds update -a
    ./scripts/feeds install -a
    make defconfig
    make -j2 package/parallax/compile V=s
    make -j2 package/luci-app-parallax/compile V=s

luci-i18n-parallax-ru is generated by luci.mk from the PO catalog. The workflow requires
exactly one APK for each of the three package names before proceeding to QEMU.

Use the workflow logs and artifacts as evidence. Do not treat the SDK compilation or QEMU
integration tests as passed until an actual successful run has been observed.
